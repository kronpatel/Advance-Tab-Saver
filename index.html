What's New in Version 3.0.0

⭐

Favorites & Pinning

Highlight your most important links with a simple star toggle to keep them grouped at the very top of your list.

🗂️

Bulk Selection Actions

Select multiple tabs simultaneously to batch open, batch delete, or export them into clean JSON files with one single click.

🧹

Duplicate Tab Cleaner

Reclaim memory by scanning all saved URLs. Instantly remove duplicates while preserving the oldest entry date safely.

📊

Storage Analytics Grid

Track your saved tab counts, categories, and database bytes in real-time, providing immediate visibility into usage.

🎨

Three Premium Themes

Toggle between optimized HSL-derived Dark, Light, and Grey themes with smooth hardware-accelerated transitions.

💾

Local-First Architecture

Removed third-party trackers, OAuth dependencies, and logins. All data is kept on your computer, with full JSON import/export support.

Under the Hood Enhancements

🛠️ Features Added & Fixed

  • XSS vulnerabilities resolved by escaping inputs dynamically.
  • Transitioned backend logic from sync quota limits to local storage blocks.
  • Optimized transitions by mapping properties explicitly instead of wildcards.
  • Settings modal options persist reliably on reload.

🛡️ Security & Performance

  • Fully offline service worker handling session updates.
  • Cleaned up redundant dependencies and legacy OAuth client configurations.
  • Full input validation during backup imports to prevent parsing exceptions.
