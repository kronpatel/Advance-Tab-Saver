How to Install

Get the extension running in Chrome or any Chromium-based browser in less than a minute.

1 1

Download or Clone Repository

Download the project as a ZIP archive and extract it locally, or run the command below inside your terminal:

git clone https://github.com/kronpatel/Advance-Tab-Saver.git
2 2

Open chrome://extensions

Open Google Chrome, type chrome://extensions in the URL address bar, and hit Enter to access the developer dashboard.

3 3

Enable Developer Mode

Toggle the Developer mode switch located in the upper-right corner of the Extensions dashboard window.

4 4

Click Load Unpacked

Click the Load unpacked button that appears in the top-left area of the screen after enabling Developer Mode.

5 5

Select Advance Tab Saver Folder

Select the directory where you extracted the repository files (the folder containing the manifest.json file).

6 6

Start Saving Tabs

The extension icon will now appear in your browser toolbar. Click the puzzle icon, pin Tab Saver Pro, and start saving tabs!
