# Security Policy

We take the security of Tab Saver Pro seriously. If you believe you have found a security vulnerability, please report it to us using the instructions below.

## Supported Versions

Only the latest major version receives security updates. We recommend always running the latest version available on the Chrome Web Store or Firefox Add-ons site.

| Version | Supported |
| :--- | :--- |
| 3.2.x | :white_check_mark: Yes |
| 3.1.x | :x: No |
| < 3.0.0 | :x: No |

## Reporting a Vulnerability

**Please do not open a public GitHub issue for security vulnerabilities.**

Instead, report vulnerabilities privately by sending an email to **security@kerzox.com**.

When reporting, please include:
- A description of the vulnerability and its potential impact.
- Step-by-step instructions to reproduce the issue (including any sample import files or payloads).
- Browser type, version, and OS platform.

## Response Timeline

- **Triage**: We will acknowledge and triage reports within **48 hours** of receipt.
- **Remediation**: If verified, we aim to implement a security patch and submit updates to the respective browser web stores within **7 business days**.
- **Disclosure**: We follow coordinated vulnerability disclosure guidelines. A security advisory will be published along with the patched tag release.
